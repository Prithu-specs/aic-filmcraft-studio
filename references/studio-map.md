This map records how the public AI Filmmaking Studio material was translated into AIC Filmcraft Studio. It is an implementation map, not a copy of that material.

| Production workflow and gates | eight stages plus G0–G5 quality gates |
| Ownership, authority, handoffs | producer authority, integrator rule, active-version controls |
| State tracking and project recovery | portable ledger, asset/attempt/review/delivery records, archive recovery test |
| Project kit | brief, canon, scene packets, source assets, approved clips, edit, audio, delivery, archive |
| Creator manual | preflight, targeted repair, edit/mix, master verification procedures |

| Case studies and worked examples | general lessons only; project-specific characters, scripts, deadlines, and assets are never carried forward automatically |

## Eight-stage production map

1. **Brief and authority** — intake, mandate, audience, destination, budget, risk, tool verification, rights.
2. **Story and performance** — dramatic engine, characters, beats, screenplay, direction.
3. **Visual canon and assets** — locked creative rules, asset registry, reference scope, change log.
4. **Scene and shot design** — timed scene packets, coverage, camera, art, light, sound, continuity.
5. **Preflight and generation** — current model settings, references, acceptance test, attempt ledger, fallback.
6. **Review and repair** — creative, continuity, technical, rights/accessibility lanes; seam review; targeted repair.
7. **Edit, sound, and finish** — editorial second writing pass, sound spotting/mix, picture lock, master.
8. **Deliver and learn** — release checks, destination proof, portable archive, recovery test, reusable lesson.

## Boundaries

The site’s provider pages, prices, limits, community examples, case studies, named prompts, and external references are time- and context-dependent. AIC Filmcraft Studio retains the operating principles while requiring the current production to verify its own tools, costs, permissions, and destination rules.
